# HU-S10-01 — Catálogo semilla de habilidades y comando de carga

Estado: completada y verificada el 12 de noviembre de 2026.

## Alcance

Historia aprobada en `docs/sprint-10.md`. El catálogo de habilidades es abierto: arrancaba vacío y lo llenaba quien escribía primero cada habilidad. El comando `php artisan skills:seed` carga el catálogo curado `backend/database/data/skills/top_skills.csv`: 820 habilidades para Educación Dual (757 técnicas y 63 blandas), 12 de ellas con alias. Los criterios de curaduría están en `backend/database/data/skills/README.md`.

No cambia ninguna ruta ni la interfaz.

## Uso

```bash
docker compose exec backend php artisan skills:seed
```

Salida: `Catálogo semilla: 820 habilidades; 820 agregadas, 0 actualizadas, 0 sin cambios.` Se ejecuta en cada entorno después de `migrate` y cada vez que cambie el CSV. La opción `--path=` carga otro archivo con la misma cabecera.

## Formato del archivo

| Columna | Contenido |
| --- | --- |
| `name` | Nombre visible, de hasta 80 caracteres. |
| `kind` | `technical` o `soft`. |
| `aliases` | Opcional. Abreviaturas o nombres alternos separados por `\|`: `c sharp\|csharp`. |

Alias iniciales: `js` (JavaScript), `ts` (TypeScript), `c sharp` y `csharp` (C#), `cpp` (C++), `golang` (Go), `k8s` (Kubernetes), `ml` y `machine learning` (Aprendizaje automático), `dl` y `deep learning` (Aprendizaje profundo), `nlp` y `pln` (Procesamiento de lenguaje natural), `bi` y `business intelligence` (Inteligencia de negocios) y `bd` (Modelado y Normalización de bases de datos).

## Decisiones

| Tema | Decisión |
| --- | --- |
| Qué actualiza (CA-02) | Para una habilidad que ya existe (por `slug`), el comando corrige `kind` y `aliases` con los del archivo. Nunca cambia `name` ni `id`, y no toca las habilidades que no están en el archivo. |
| Cambio de regla | Antes, quien registraba primero una habilidad fijaba su tipo para siempre. Ahora el catálogo curado manda sobre el tipo de las habilidades que contiene. Las altas desde el CV y las oportunidades (`SkillCatalog::ids`) siguen sin modificar habilidades existentes. |
| Idempotencia | Solo escribe las filas que difieren, así que una segunda ejecución no cambia nada (ni `updated_at`). El comando informa agregadas, actualizadas y sin cambios. |
| Integridad | Toda la carga corre en una transacción, con las filas existentes bloqueadas (`FOR UPDATE`). Las nuevas se insertan con `insertOrIgnore`, por si otra cuenta registra la misma habilidad a la vez. |
| Validación (CA-03) | `SkillSeedCatalog::rows()` valida el archivo completo antes de escribir: cabecera, tres columnas, nombre no vacío de hasta 80 caracteres, `kind` del enum y ningún slug repetido. Un renglón inválido detiene la carga con su número. |
| Alias | Se normalizan con `CatalogSlug::from` (minúsculas, sin acentos). Se descartan los vacíos, los repetidos y los iguales al slug de su habilidad. Un mismo alias puede apuntar a varias habilidades. El generador rechaza un alias igual al nombre de otra habilidad. |
| Almacenamiento | Columna `skills.aliases` (`jsonb`, arreglo), creada por la migración de T-S10-01. |
| Comando y no migración (CA-04) | Las pruebas parten de un catálogo vacío (`StudentCvTest` comprueba `Skill::count()` exacto) y el catálogo es vivo. |
| Fuente editable | El CSV se genera con `scripts/skills/build-top-skills.py`. Las habilidades y el diccionario `ALIASES` se editan ahí, no en el CSV. |

## Cobertura de aceptación

Pest: `tests/Feature/SkillSeedTest.php`. `SkillFuzzySearchTest` busca sobre el catálogo sembrado.

| Criterio | Verificación |
| --- | --- |
| CA-01 | Carga las 820 habilidades con nombre, tipo y alias (`JavaScript` con `js`, `C#` con `c sharp` y `csharp`). «bd» queda en dos habilidades. El archivo real tiene al menos 5 habilidades con alias. |
| CA-02 | Segunda ejecución: 0 agregadas, 0 actualizadas, y la tabla idéntica, incluido `updated_at`. Una habilidad previa `javascript` de tipo `soft` pasa a `technical` con alias `js` y conserva su nombre y su id. Una habilidad ajena al archivo queda intacta. |
| CA-03 | Archivos inválidos (cabecera anterior, columna faltante, tipo desconocido, nombre vacío o de más de 80, alias de más de 80, slug repetido) y archivo inexistente: el comando falla y no escribe nada. Los alias se normalizan y se descartan los vacíos y redundantes. |
| CA-04 | Después de migrar, el catálogo está vacío. `StudentCvTest` pasa sin cambios en sus conteos. |
| CA-05 | Todas las anteriores. |
