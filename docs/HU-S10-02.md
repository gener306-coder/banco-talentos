# HU-S10-02 — Prevención de selección accidental en sugerencias difusas

Estado: completada y verificada el 12 de noviembre de 2026.

## Alcance

Historia aprobada en `docs/sprint-10.md`. Depende de T-S10-01, que agrega `match` a cada sugerencia de `GET /api/skills`. El `SkillPicker` (CV del alumno y oportunidades duales) preselecciona las sugerencias por prefijo o por alias, pero ya no una aproximada, para que Enter no registre «Vuex» cuando se escribió «Vue».

## Comportamiento

| Primera opción visible | Preselección | Enter |
| --- | --- | --- |
| Sugerencia por prefijo (`match: "prefix"`) | Sí, como antes (CA-01) | Agrega esa sugerencia del catálogo, con su tipo. |
| Sugerencia por alias (`match: "alias"`) | Sí (CA-01) | Agrega esa sugerencia: escribir «js» y Enter agrega JavaScript. |
| Sugerencia aproximada (`match: "fuzzy"`) | No (CA-02) | Agrega lo escrito como habilidad nueva, con el tipo elegido. |
| «Agregar … como nueva» (sin sugerencias) | No | Agrega lo escrito, igual que antes. |

Una sugerencia aproximada se elige con las flechas y Enter, o con un clic. Las flechas recorren todas las opciones como antes.

## Decisiones

| Tema | Decisión |
| --- | --- |
| Preselección calculada | La preselección ya no se guarda al llegar los resultados. El componente guarda solo la opción elegida con las flechas (`selected`, `null` mientras el usuario no navega) y calcula la activa en cada render a partir de la **primera opción visible**. |
| Habilidades ya elegidas | Las habilidades ya agregadas no se muestran como sugerencias. Si la sugerencia por prefijo ya está en la lista, la primera visible puede ser aproximada, y tampoco se preselecciona. Mirar solo el primer resultado de la API la habría preseleccionado. |
| Contrato estricto | `searchSkills` devuelve `SkillSuggestion` (`CvSkill` con `match`). Una respuesta sin `match` válido se trata como respuesta inválida (502), igual que el resto del cliente del CV. |
| Presentación | Sin cambios visuales: la opción aproximada se ve igual que las demás, pero no queda resaltada. |

## Archivos

- `frontend/src/students/cv.ts`: tipos `SkillMatch` y `SkillSuggestion`, y validación de `match`.
- `frontend/src/students/SkillPicker.tsx`: preselección solo por prefijo o alias.

## Cobertura de aceptación

Vitest: `src/students/StudentCvPage.test.tsx` y `src/students/cv.test.ts`. `src/opportunities/OpportunitiesPage.test.tsx` cubre el mismo picker en las oportunidades. Playwright: `e2e/students.spec.ts` (capturar y recuperar una habilidad del catálogo real).

| Criterio | Verificación |
| --- | --- |
| CA-01 | Con React (prefijo) seguido de Preact (aproximada), React queda preseleccionada y Enter la agrega. Con «js» y JavaScript por alias, queda preseleccionada y Enter agrega JavaScript, no «js». Las pruebas anteriores de preselección (Liderazgo, PLC) siguen pasando. |
| CA-02 | Con «Vue» y la sugerencia aproximada «Vuex», ninguna opción queda `aria-selected` ni hay `aria-activedescendant`, y Enter agrega «Vue». Con «javscript», la sugerencia aproximada JavaScript se elige con ArrowDown y Enter. Si la sugerencia por prefijo ya está en la lista, la aproximada que queda primero no se preselecciona. |
| CA-03 | Las pruebas anteriores, sobre la bandera `match` de la respuesta simulada. El cliente acepta `prefix`, `alias` y `fuzzy`, y rechaza sugerencias sin `match` o con un valor desconocido. |
