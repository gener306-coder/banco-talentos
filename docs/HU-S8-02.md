# HU-S8-02 — Continuar con el expediente después de registrar un alumno

Estado: completada y verificada el 29 de octubre de 2026 (solo interfaz; no cambia la API).

## Alcance

Historia aprobada en `docs/sprint-8.md`. Al registrar un alumno desde la hoja «Registrar alumno», la institución elige entre completar de inmediato el expediente del alumno recién creado o registrar otro, en lugar de tener que buscarlo después en el padrón.

## Decisiones

| Tema | Decisión |
| --- | --- |
| Pregunta al registrar (CA-01) | Tras el `201`, la hoja sustituye el formulario por la confirmación «Alumno registrado: {nombre}. ¿Qué quieres hacer ahora?» (`role="status"`), una línea que explica las opciones y dos botones: **Completar expediente** (principal) y **Registrar otro alumno** (secundario). Cerrar la hoja con **Cerrar** o `Esc` sigue disponible. El formulario se oculta mientras se elige para que la decisión sea explícita. |
| Registrar otro (CA-01) | Vuelve al formulario vacío con el foco en «Matrícula o control interno»: el comportamiento anterior a esta historia. |
| Completar expediente (CA-02) | `StudentForm` recibe `onCompleteProfile`; `StudentsPage` navega a `/students/{id}` con el estado de navegación `{ completeProfile: true }`. `StudentDetailPage` lee ese estado una sola vez y, al cargar el alumno, desplaza la vista y pone el foco en «Carrera o programa educativo», el primer campo del **Expediente público**. Abrir el detalle por otro camino no mueve el foco. |
| Padrón actualizado (CA-03) | El alta sigue refrescando el padrón (`onCreated`), así que al volver aparece el alumno, con o sin la búsqueda de HU-S8-01. |
| Accesibilidad (CA-04) | El foco pasa a **Completar expediente** al mostrar la confirmación; todo el flujo funciona con teclado (Intro sobre el botón enfocado). |
| API | Sin cambios: no hay fase de backend ni pruebas Pest nuevas. |

## Cobertura de aceptación

Vitest: `src/students/StudentsPage.test.tsx`. E2E: `e2e/students.spec.ts` y `e2e/talent-search.spec.ts`, cuyo recorrido principal ya usa **Completar expediente** para llegar al expediente.

| Criterio | Verificación |
| --- | --- |
| CA-01 | Vitest: tras registrar, la confirmación sustituye al formulario; **Registrar otro alumno** devuelve el formulario vacío con el foco en la matrícula y sin cambiar de ruta. E2E: el registro de varios alumnos seguidos usa **Registrar otro alumno**. |
| CA-02 | Vitest: **Completar expediente** cierra la hoja, abre `/students/9` y el foco queda en «Carrera o programa educativo». E2E: con Intro sobre el botón enfocado se abre el detalle y el campo queda enfocado. |
| CA-03 | Vitest: el padrón se vuelve a pedir tras el alta y muestra al alumno. E2E: al volver, la búsqueda encuentra al alumno nuevo. |
| CA-04 | Vitest y E2E: el foco está en **Completar expediente** al aparecer la confirmación, que se anuncia con `role="status"`. |
